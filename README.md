Sandhya Sales Dashboard

Project Overview

An interactive Power BI dashboard designed to analyze business sales performance and provide meaningful insights through data visualization.

Dashboard Pages

* Page 1: Business Sales Dashboard
* Page 2: Sandhya Sales Dashboard

Key Performance Indicators (KPIs)

* Total Sales
* Total Profit
* Total Quantity
* Total Orders
* Average Delivery Days

Tools & Technologies

* Microsoft Power BI
* Data Visualization
* Business Intelligence

Key Insights

* Sales performance by category and subcategory
* Monthly sales and profit trends
* Sales analysis by region and salesperson
* Payment mode and order status analysis
